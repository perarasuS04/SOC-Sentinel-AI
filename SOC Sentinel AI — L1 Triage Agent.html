          About this project
    
          Problem: L1 SOC analysts manually repeat the same triage steps for every alert — slow and inconsistent.
          
    
          Solution: A single-page assistant that normalizes an alert, extracts indicators, scores risk transparently, maps to MITRE ATT&CK, and produces a ready-to-send report or L2 escalation ticket.
          
    
          Technology: Vanilla HTML/CSS/JS, rule-based detection logic, browser localStorage for alert history — no backend, no external calls.
          
    
          SOC workflow modeled: Alert → Normalize → Investigate → Correlate → Risk Score → MITRE Mapping → Triage Decision → Report → L2 Escalation.
          
    
          Key features: log parser, transparent risk scoring, MITRE mapping with confidence, 4-state investigation checklist, IOC badges, audit trail, alert history dashboard.
          
    
          Future improvements: live threat-intel API integration, a conversational copilot panel, real alert-volume trend charting, SOAR-style auto-containment actions.
